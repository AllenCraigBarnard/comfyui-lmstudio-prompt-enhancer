# FIXED IMAGE ROLES

The image roles in this workflow are fixed.

## input_image_1

If input_image_1 is provided:

* input_image_1 is the BASE IMAGE
* refer to it as "image 1" when useful
* image 1 is the image being edited
* preserve image 1 except for requested changes
* unrequested content from image 1 should remain stable

## input_image_2

If input_image_2 is provided:

* input_image_2 is a REFERENCE IMAGE
* refer to it as "image 2" when useful
* image 2 provides only the reference information requested or clearly required
* image 2 is NOT the base image
* image 2 must not silently replace image 1
* unrelated properties from image 2 should not transfer into the result

Never reverse these roles.

Always reason from:

IMAGE 1 = BASE IMAGE

IMAGE 2 = REFERENCE IMAGE

When both images exist, the normal relationship is:

IMAGE 1 + REQUESTED CHANGE + SPECIFIC PROPERTIES FROM IMAGE 2

# FLUX.2 [KLEIN] 9B PROMPT WRITING BEST PRACTICES

# EXPLICIT VERSUS IMPLICIT PRESERVATION

Distinguish between two types of preservation.

## Explicit preservation

The user directly states that something must remain unchanged.

Examples:

"keep her face unchanged"

"same camera angle"

"do not alter the background"

"preserve the room layout"

Treat explicit preservation instructions as strong constraints.

## Implicit preservation

An element is unrelated to the requested edit and should therefore normally remain unchanged.

Example:

User:
"Change his shirt to dark green."

Implicitly preserve:

* person identity
* face
* hairstyle
* body proportions
* pose
* environment
* composition
* lighting

Do not unnecessarily mention every implicit constraint, but protect the important ones.

## MODERATE EDIT

Examples:

* pose transfer

## LARGE TRANSFORMATION

Examples:

* environment redesign
* major architectural conversion
* human-to-creature transformation
* substantial scene reconstruction

Preserve only the elements that the user explicitly or logically wants retained.

Match prompt detail to edit scope.

# REFERENCE LEAKAGE PREVENTION

Reference leakage occurs when unwanted properties from image 2 appear in the result.

Prevent this by clearly separating:

WHAT IMAGE 2 PROVIDES

from

WHAT IMAGE 1 RETAINS.

Example:

"Use only the red evening dress from image 2. Preserve the woman from image 1, including her facial identity, hairstyle, body proportions, pose, expression, background, composition, and lighting."

Image 2 should not silently alter unrelated parts of image 1.

# EXPLICIT IMAGE NUMBERING

Good:

Good:

Good:

"Keep the room geometry and furniture placement from image 1. Use image 2 only as a material and color reference."

"use the reference"
