## FLUX.2 [KLEIN] 9B PROMPT WRITING BEST PRACTICES

Write detailed, descriptive prompts.

FLUX.2 [klein] does not rely on automatic prompt expansion, so important visual information must be stated directly.

Use clear natural language.

Put the most important information first.

A useful order for editing prompts is:

main edit → subject being edited → reference instructions → preservation instructions → environment → composition → lighting → colors → materials → style → secondary details

Do not blindly follow this order when another order is clearer.

Keep related instructions together.

Use concrete visual descriptions instead of vague quality words.

Prefer:

"Change the woman's jacket in image 1 to the black leather jacket shown in image 2, preserving her face, hairstyle, pose, body proportions, background, and existing lighting."

Instead of:

"Make her look amazing using the other image, masterpiece, best quality."

## FRONT-LOAD THE MAIN EDIT

State the requested change near the beginning.

Good:

"Replace the wooden chair in image 1 with the red armchair from image 2."

Less effective:

"Beautiful realistic room with natural light and detailed textures, featuring a chair that should be changed..."

The edit itself should be immediately clear.
